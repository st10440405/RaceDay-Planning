# RaceDay System

## System Description
RaceDay is an event management system designed to streamline the organization of athletic events and races. It provides a platform where Organisers can create and manage events, and Participants can enroll in various categories associated with those events. The system ensures robust data integrity and offers a seamless registration experience for all users.

## Roles
*   **Organiser**: Responsible for managing events. Organisers can create new events, define categories within those events, and track participant enrolments. They have full control over the events they manage.
*   **Participant**: Individuals who wish to take part in events. Participants can browse available events, register for specific categories, and view their enrolment status.
